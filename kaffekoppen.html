Övning: Från UML till C#

Kaféet Kaffekoppen – ett kassaprogram i konsolen. Vi går från kravtext → klassdiagram → kod.

Så läser du diagrammet

  • Ofylld triangel = arv. Dryck, Smörgås och Bakverk är produkter.
  • 1 → 0..* = en beställning innehåller noll eller flera produkter → blir en List<Product>.
  • # = protected så att subklasserna kommer åt namn och pris. - = private. + = public.
  • Subklasserna listar bara de metoder de skriver om (override).

Steg 4: Från diagram till C#

Produkt – basklassen

Metoderna är virtual så att varje produkttyp kan räkna ut sitt eget pris (krav 6).

class Product
{
    protected string name;
    protected decimal basePrice;

    public Product(string productName, decimal price)
    {
        name = productName;
        basePrice = price;
    }

    public virtual decimal CalculatePrice()
    {
        return basePrice;
    }

    public virtual bool CanBeSold()
    {
        return true;
    }

    public virtual string Description()
    {
        return name;
    }
}

Dryck – pris beror på storlek (krav 2)

class Drink : Product
{
    private string size;

    public Drink(string productName, decimal price, string chosenSize) : base(productName, price)
    {
        size = chosenSize;
    }

    public override decimal CalculatePrice()
    {
        if (size == "mellan")
        {
            return basePrice + 5;
        }
        if (size == "stor")
        {
            return basePrice + 10;
        }
        return basePrice;
    }

    public override string Description()
    {
        return name + " (" + size + ")";
    }
}

Smörgås – syns på kvittot om den är vegetarisk (krav 3)

class Sandwich : Product
{
    private bool isVegetarian;

    public Sandwich(string productName, decimal price, bool vegetarian) : base(productName, price)
    {
        isVegetarian = vegetarian;
    }

    public override string Description()
    {
        if (isVegetarian)
        {
            return name + " (vegetarisk)";
        }
        return name;
    }
}

Bakverk – halva priset sista dagen, nekas efter (krav 4)

class Pastry : Product
{
    private DateTime bestBefore;

    public Pastry(string productName, decimal price, DateTime date) : base(productName, price)
    {
        bestBefore = date;
    }

    public override bool CanBeSold()
    {
        return bestBefore >= DateTime.Today;
    }

    public override decimal CalculatePrice()
    {
        if (bestBefore == DateTime.Today)
        {
            return basePrice / 2;
        }
        return basePrice;
    }

    public override string Description()
    {
        if (bestBefore == DateTime.Today)
        {
            return name + " (halva priset)";
        }
        return name;
    }
}

Beställning – vet inte vilka produkttyper den har (krav 6–8)

class Order
{
    private List<Product> products = new List<Product>();
    public bool IsStudent { get; set; }

    public bool Add(Product product)
    {
        if (!product.CanBeSold())
        {
            return false;
        }
        products.Add(product);
        return true;
    }

    public decimal Subtotal()
    {
        decimal sum = 0;
        foreach (Product p in products)
        {
            sum += p.CalculatePrice();   // Order vet inte vilken typ p är!
        }
        return sum;
    }

    public decimal Discount()
    {
        decimal sum = Subtotal();
        decimal studentDiscount = 0;
        decimal volumeDiscount = 0;

        if (IsStudent)
        {
            studentDiscount = sum / 10;   // 10 %
        }
        if (sum > 200)
        {
            volumeDiscount = sum / 20;     // 5 %
        }

        // Rabatterna kan inte kombineras – den största vinner
        if (studentDiscount > volumeDiscount)
        {
            return studentDiscount;
        }
        return volumeDiscount;
    }

    public decimal Total()
    {
        return Subtotal() - Discount();
    }

    public void PrintReceipt()
    {
        Console.WriteLine();
        Console.WriteLine("===== KAFFEKOPPEN =====");
        foreach (Product p in products)
        {
            Console.WriteLine(p.Description() + ": " + p.CalculatePrice() + " kr");
        }
        Console.WriteLine("-----------------------");
        Console.WriteLine("Delsumma: " + Subtotal() + " kr");
        Console.WriteLine("Rabatt: -" + Discount() + " kr");
        Console.WriteLine("Att betala: " + Total() + " kr");
    }
}

Det här är polymorfism. p.CalculatePrice() anropar Dryckens, Smörgåsens eller Bakverkets version – beroende på vad p faktiskt är. Lägger vi till en ny produkttyp behöver Order inte ändras alls.

Program.cs – menyn (krav 9)

Order order = new Order();

while (true)
{
    Console.WriteLine();
    Console.WriteLine("1. Kaffe          30 kr");
    Console.WriteLine("2. Ostsmörgås     55 kr  (vegetarisk)");
    Console.WriteLine("3. Skinksmörgås   60 kr");
    Console.WriteLine("4. Kanelbulle     35 kr  (bäst före idag)");
    Console.WriteLine("5. Croissant      30 kr  (bäst före igår)");
    Console.WriteLine("0. Klar");
    Console.Write("Välj: ");
    string choice = Console.ReadLine();

    if (choice == "0")
    {
        break;
    }

    Product product;

    if (choice == "1")
    {
        Console.Write("Storlek (liten, mellan, stor): ");
        string size = Console.ReadLine();
        product = new Drink("Kaffe", 30, size);
    }
    else if (choice == "2")
    {
        product = new Sandwich("Ostsmörgås", 55, true);
    }
    else if (choice == "3")
    {
        product = new Sandwich("Skinksmörgås", 60, false);
    }
    else if (choice == "4")
    {
        product = new Pastry("Kanelbulle", 35, DateTime.Today);
    }
    else if (choice == "5")
    {
        product = new Pastry("Croissant", 30, DateTime.Today.AddDays(-1));
    }
    else
    {
        Console.WriteLine("Ogiltigt val.");
        continue;
    }

    if (order.Add(product))
    {
        Console.WriteLine(product.Description() + " tillagd.");
    }
    else
    {
        Console.WriteLine(product.Description() + " har gått ut och kan inte säljas.");
    }
}

Console.Write("Är kunden student? (j/n): ");
order.IsStudent = Console.ReadLine() == "j";
order.PrintReceipt();
