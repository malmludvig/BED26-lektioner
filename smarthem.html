Övning: Smarta hemmet

Lägenhet 4B – ett konsolprogram som styr taklampa, högtalare och termostat. Vi går från kravtext → klassdiagram → kod.

Steg 2: Behövs en basklass?

Kraven säger att förmågorna ska vara interface. Men titta på vad enheterna gör: alla tre slås på och av på exakt samma sätt, och alla tre kontrollerar sitt intervall på exakt samma sätt. Det enda som skiljer är siffrorna.

Tumregel från lektionen: delar klasserna kod → basklass. Delar de bara förmåga → interface. Här gäller båda! Vi skriver koden en gång i en abstrakt basklass SmartDevice, och låter den implementera båda interfacen. Då gör alla subklasser det också.

Utan basklass hade vi behövt skriva TurnOn, TurnOff och Adjust tre gånger – en gång i varje klass.

Så läser du diagrammet

  • Streckad linje + ofylld triangel = implementerar ett interface. SmartDevice kan slås på och av, och kan justeras.
  • Heldragen linje + ofylld triangel = arv. En taklampa är en smart enhet.
  • «abstract» = man kan inte skriva new SmartDevice(…), bara skapa någon av subklasserna.
  • Name finns i båda interfacen, så att menyn kan skriva ut namnet oavsett vilket interface den har framför sig. En enda egenskap i klassen uppfyller båda.

Steg 4: Från diagram till C#

Interfacen – förmågorna

interface ISwitchable
{
    string Name { get; }
    bool IsOn { get; }
    void TurnOn();
    void TurnOff();
}

interface IAdjustable
{
    string Name { get; }
    string Quantity { get; }      // "ljusstyrka", "volym", "temperatur"
    int Min { get; }
    int Max { get; }
    int Value { get; }
    string Unit { get; }    // "%", "°C" eller "" om det inte finns någon
    bool Adjust(int newValue);
}

SmartEnhet – den gemensamma koden

Egenskaperna har private set på IsOn och Value. Bara klassen själv får ändra dem – via TurnOn, TurnOff och Adjust. Det är inkapsling.

abstract class SmartDevice : ISwitchable, IAdjustable
{
    public string Name { get; }
    public string Room { get; }
    public bool IsOn { get; private set; }   // false från början = avstängd

    public string Quantity { get; }
    public int Min { get; }
    public int Max { get; }
    public int Value { get; private set; }
    public string Unit { get; }

    protected SmartDevice(string name, string room, string quantity, int min, int max, int startValue, string unit)
    {
        Name = name;
        Room = room;
        Quantity = quantity;
        Min = min;
        Max = max;
        Value = startValue;
        Unit = unit;
    }

    public void TurnOn()
    {
        IsOn = true;
    }

    public void TurnOff()
    {
        IsOn = false;
    }

    public bool Adjust(int newValue)
    {
        // En avstängd enhet går inte att justera, och värdet måste ligga i intervallet
        if (!IsOn || newValue < Min || newValue > Max)
        {
            return false;
        }
        Value = newValue;
        return true;
    }
}

Taklampa, Högtalare och Termostat

Subklasserna skickar bara in sina egna värden till basklassens konstruktor med base(…).

class CeilingLamp : SmartDevice
{
    public CeilingLamp(string room) : base("Taklampa", room, "ljusstyrka", 1, 100, 100, "%") { }
}

class Speaker : SmartDevice
{
    public Speaker(string room) : base("Högtalare", room, "volym", 0, 50, 10, "") { }
}

class Thermostat : SmartDevice
{
    public Thermostat(string room) : base("Termostat", room, "temperatur", 10, 30, 20, "°C") { }
}

Program.cs – menyn

Titta noga: CeilingLamp, Speaker och Thermostat nämns bara i listan överst. Resten av programmet pratar med enheterna via ISwitchable och IAdjustable.

// Det enda stället som känner till de konkreta klasserna
List<SmartDevice> devices = new List<SmartDevice>
{
    new CeilingLamp("Vardagsrummet"),
    new Speaker("Vardagsrummet"),
    new Thermostat("Hallen")
};

while (true)
{
    Console.WriteLine();
    Console.WriteLine("=== Smarta hemmet 4B ===");
    Console.WriteLine("1. Visa alla enheter");
    Console.WriteLine("2. Slå på eller av");
    Console.WriteLine("3. Justera");
    Console.WriteLine("4. Stäng av alla");
    Console.WriteLine("5. Avsluta");
    Console.Write("Val: ");
    string choice = Console.ReadLine();
    Console.WriteLine();

    if (choice == "1")
    {
        ShowAll(devices);
    }
    else if (choice == "2")
    {
        SmartDevice device = ChooseDevice(devices, "Enheter:");
        if (device != null)
        {
            Toggle(device);
        }
    }
    else if (choice == "3")
    {
        SmartDevice device = ChooseDevice(devices, "Enheter som kan justeras:");
        if (device != null)
        {
            Adjust(device);
        }
    }
    else if (choice == "4")
    {
        foreach (ISwitchable e in devices)
        {
            e.TurnOff();
        }
        Console.WriteLine("Alla enheter är avstängda.");
    }
    else if (choice == "5")
    {
        break;
    }
    else
    {
        Console.WriteLine("Ogiltigt val.");
    }
}

static void ShowAll(List<SmartDevice> devices)
{
    foreach (SmartDevice e in devices)
    {
        string state = e.IsOn ? "PÅ" : "AV";
        string line = $"{e.Room,-14} {e.Name,-14} {state}";

        if (e.IsOn)
        {
            line += "   " + WithUnit(e, e.Value.ToString());
        }
        Console.WriteLine(line);
    }
}

static SmartDevice ChooseDevice(List<SmartDevice> devices, string heading)
{
    Console.WriteLine(heading);
    for (int i = 0; i < devices.Count; i++)
    {
        Console.WriteLine($"{i + 1}. {devices[i].Name}");
    }
    Console.Write("Välj enhet: ");

    if (int.TryParse(Console.ReadLine(), out int number) && number >= 1 && number <= devices.Count)
    {
        return devices[number - 1];
    }
    Console.WriteLine("Ogiltigt val.");
    return null;
}

static void Toggle(ISwitchable device)
{
    if (device.IsOn)
    {
        device.TurnOff();
        Console.WriteLine($"{device.Name} är nu avstängd.");
    }
    else
    {
        device.TurnOn();
        Console.WriteLine($"{device.Name} är nu på.");
    }
}

static void Adjust(IAdjustable device)
{
    // Kan enheten också slås av – och är den av just nu?
    if (device is ISwitchable switchable && !switchable.IsOn)
    {
        Console.WriteLine($"{device.Name} är avstängd. Slå på den först.");
        return;
    }

    Console.Write($"Ny {device.Quantity} ({RangeText(device)}): ");
    if (int.TryParse(Console.ReadLine(), out int value) && device.Adjust(value))
    {
        Console.WriteLine($"{device.Name} är inställd på {WithUnit(device, value.ToString())}.");
    }
    else
    {
        Console.WriteLine($"Ogiltigt värde. {device.Name} accepterar {RangeText(device)}.");
    }
}

// "10-30" blir "10-30 °C", men högtalarens "0-50" får ingen måttenhet
static string WithUnit(IAdjustable device, string text)
{
    if (device.Unit == "")
    {
        return text;
    }
    return text + " " + device.Unit;
}

static string RangeText(IAdjustable device)
{
    return WithUnit(device, device.Min + "-" + device.Max);
}

Lägg märke till parametrarna. Toggle tar en ISwitchable och Adjust tar en IAdjustable. Metoderna vet inte att det finns taklampor – bara att det finns saker som kan slås på och saker som kan justeras. Vi skickar in en SmartDevice, och det fungerar eftersom den implementerar båda.

Klart när

  • ☑ Alla tre enheter kan slås på och av – Toggle via ISwitchable.
  • ☑ En avstängd enhet nekas justering, och ett värde utanför intervallet nekas med besked om rätt intervall.
  • ☑ "Stäng av alla" fungerar – en loop över alla som ISwitchable.
  • ☑ Menylogiken känner inte till de konkreta enhetsklasserna – de nämns bara där listan skapas.

Utmaning: En persienn

Lägg till en persienn i sovrummet som kan öppnas 0–100 %, utan att ändra i menyn.

Visa facit

En ny klass:

class Blind : SmartDevice
{
    public Blind(string room) : base("Persienn", room, "öppning", 0, 100, 0, "%") { }
}

Och en ny rad där enheterna skapas:

List<SmartDevice> devices = new List<SmartDevice>
{
    new CeilingLamp("Vardagsrummet"),
    new Speaker("Vardagsrummet"),
    new Thermostat("Hallen"),
    new Blind("Sovrummet")      // ny rad – inget annat ändras
};

Utskrift av "Visa alla enheter" efter att persiennen slagits på och öppnats till 40 %:

Vardagsrummet  Taklampa       AV
Vardagsrummet  Högtalare      AV
Hallen         Termostat      AV
Sovrummet      Persienn       PÅ   40 %

Varför gick det? Menyn frågar aldrig vad en enhet är, bara vad den kan. Persiennen implementerar ISwitchable och IAdjustable (via SmartDevice), så den uppfyller samma kontrakt som de andra. Loopar, val och kontroller fungerar för den direkt – det är polymorfism genom interface.
