Branches

Ett eget spår där du provar något nytt – utan att förstöra main.

main ●───●───────●───◆───● \ / studentrabatt ●───●───

Branch och merge

git switch -c studentrabatt    # ny branch
# ... ändra, add, commit ...
git switch main                # tillbaka
git merge studentrabatt        # slå ihop
git branch -d studentrabatt    # städa

Merge-konflikt

Två branches har ändrat samma rad:

<<<<<<< HEAD
            return basePrice + 5;
=======
            return basePrice + 8;
>>>>>>> studentrabatt

Välj vad som ska stå kvar, ta bort markeringarna, sedan git add + git commit.

Ett nytt repo på GitHub

När du skapar ett tomt repo visar GitHub en sida med Quick setup – och kommandona du behöver.

Kommandona från GitHub

Inget repo än – skapa ett nytt

echo "# testtest" >> README.md   # skapa en README
git init                          # gör mappen till ett repo
git add README.md
git commit -m "first commit"
git branch -M main                # döp branchen till main
git remote add origin https://github.com/malmludvig/testtest.git
git push -u origin main           # skicka upp och koppla ihop

Har redan ett repo – pusha det

git remote add origin https://github.com/malmludvig/testtest.git
git branch -M main
git push -u origin main

Har du redan gjort git init och commits? Då räcker de tre raderna till höger. Byt malmludvig/testtest mot ditt eget namn och repo.

Git i terminalen – cheat sheet

Viktigaste Git-kommandona

git initStarta ett nytt lokalt Git-repo
git statusKolla Git-status
git add .Lägg till alla ändringar till staging (här läggs allting till innan en commit)

Konfiguration

Ställ in användaren (vilket namn som helst):

git config --global user.name "Ludvig M"
git config --global user.email "m@mail.se"
git config --global --list

Kolla vilket remote repo du är kopplad till:

git remote -v

Byt Git-editor till VS Code (Vim är standard):

git config --global core.editor "code --wait"
git config --global core.editor

Branches och merge + git diff

git branchVisa vilka branches som finns och vilken du står i
git branch -a listar även remote-branches
git branch dev-branchSkapa en ny branch som heter dev-branch
git checkoutByt branch: git checkout dev-branch, git checkout main
git switchByt branch (nyare och tydligare än checkout): git switch dev-branch
git switch -c dev-branch skapar en ny branch och byter till den
git mergeMerga ihop branchen du står i med den du skriver: git merge dev-branch
git merge --abortAvbryt en merge
git diffVisa ändringar mellan arbetsmappen och staging
