LINQ

Ställ frågor till listor – filtrera, sortera och räkna med en rad kod.

Uppgift: alla tal större än 5

List<int> numbers = new List<int> { 5, 12, 3, 8, 20, 1 };
List<int> bigNumbers = new List<int>();

foreach (int x in numbers)
{
    if (x > 5)
    {
        bigNumbers.Add(x);
    }
}

Sju rader för att plocka ut några tal.

Samma sak med LINQ

List<int> bigNumbers = numbers.Where(x => x > 5).ToList();   // 12, 8, 20

Loopen säger hur. LINQ säger vad du vill ha.

using System.Linq; – finns redan med i nya konsolprojekt.

Lambda: x => x > 5

x  går till  x > 5

  • x = ett element i listan i taget
  • till höger = vad som ska räknas ut
  • namnet väljer du själv: x för tal, p för produkt

En lambda är en metod utan namn

static bool IsLarge(int x)
{
    return x > 5;
}

numbers.Where(IsLarge);       // fungerar också
numbers.Where(x => x > 5);    // men lambdan är kortare

Where – välj ut

numbers.Where(x => x < 5)                // 3, 1
numbers.Where(x => x == 8)               // 8
numbers.Where(x => x % 2 == 0)           // 12, 8, 20
numbers.Where(x => x != 3)               // 5, 12, 8, 20, 1
numbers.Where(x => x >= 5 && x <= 12)   // 5, 12, 8

Behåller de element där lambdan ger true.

Select – gör om varje

numbers.Select(x => x + 1)        // 6, 13, 4, 9, 21, 2
numbers.Select(x => x * x)        // 25, 144, 9, 64, 400, 1
numbers.Select(x => "Tal " + x)   // "Tal 5", "Tal 12", …
numbers.Select(x => x > 5)        // false, true, false, true, true, false

6 in, 6 ut – alltid lika många.

Where eller Select?

En lista av personer

List<Person> people = new List<Person>
{
    new Person("Ada", 17, 1, "Stockholm"),
    new Person("Linus", 19, 2, "Göteborg"),
    new Person("Grace", 16, 1, "Malmö"),
    new Person("Bjarne", 18, 2, "Stockholm"),
    new Person("Ola", 20, 1, "Göteborg"),
    new Person("Margaret", 17, 2, "Uppsala")
};

Person har Name, Age, ClassId och City. Nu är p en hel person.

Where på personer

people.Where(p => p.Age < 18)                  // Ada, Grace, Margaret
people.Where(p => p.City == "Stockholm")       // Ada, Bjarne
people.Where(p => p.ClassId == 2)              // Linus, Bjarne, Margaret
people.Where(p => p.City != "Göteborg")        // Ada, Grace, Bjarne, Margaret
people.Where(p => p.Age >= 17 && p.Age <= 18)  // Ada, Bjarne, Margaret

Ut kommer hela personer – bara färre.

Select på personer

people.Select(p => p.Name)                 // "Ada", "Linus", "Grace", …
people.Select(p => p.Age + 1)              // 18, 20, 17, 19, 21, 18
people.Select(p => p.City.ToUpper())       // "STOCKHOLM", "GÖTEBORG", …
people.Select(p => $"{p.Name} ({p.Age})")  // "Ada (17)", "Linus (19)", …
people.Select(p => p.Age >= 18)            // false, true, false, true, true, false

6 in, 6 ut – men inte längre personer. Select kan byta typ.

Sortera

numbers.OrderBy(x => x)            // 1, 3, 5, 8, 12, 20
numbers.OrderByDescending(x => x)  // 20, 12, 8, 5, 3, 1

Hämta ett element

numbers.First()                       // 5
numbers.First(x => x > 10)            // 12
numbers.Last()                        // 1
numbers.FirstOrDefault(x => x > 100)  // 0 – inget hittades
numbers.First(x => x > 100)           // KRASCHAR

Osäker på om något hittas? Använd FirstOrDefault.

Ja/nej-frågor

numbers.Any(x => x > 15)   // true – finns det något?
numbers.All(x => x > 0)    // true – stämmer det för alla?
numbers.Contains(8)        // true – finns just 8?

Räkna

numbers.Count()             // 6
numbers.Count(x => x > 5)   // 3
numbers.Sum()               // 49
numbers.Min()               // 1
numbers.Max()               // 20
numbers.Average()           // 8,1666…

Från fråga till lista

IEnumerable<int> query = numbers.Where(x => x > 5);
List<int>        list  = numbers.Where(x => x > 5).ToList();

Where, Select och OrderBy ger en IEnumerable<T> – ett generiskt interface. Vill du ha en lista: .ToList().

LINQ på egna objekt

List<Product> menu = new List<Product>
{
    new Product("Kaffe", 30, "Dryck"),
    new Product("Te", 25, "Dryck"),
    new Product("Ostsmörgås", 55, "Smörgås"),
    new Product("Skinksmörgås", 60, "Smörgås"),
    new Product("Kanelbulle", 35, "Bakverk"),
    new Product("Croissant", 30, "Bakverk")
};

Product har egenskaperna Name, Price och Category.

Frågor till menyn

menu.Where(p => p.Price < 40)          // Kaffe, Te, Kanelbulle, Croissant
menu.Where(p => p.Category == "Dryck")  // Kaffe, Te
menu.Select(p => p.Name)               // bara namnen
menu.OrderBy(p => p.Price)             // Te först
menu.Sum(p => p.Price)                  // 235

Nu är p en hel produkt – med punkt når du egenskaperna.

Kedja ihop

List<string> cheapNames = menu
    .Where(p => p.Price < 40)    // 1. välj billiga
    .OrderBy(p => p.Price)       // 2. sortera
    .Select(p => p.Name)         // 3. ta bara namnen
    .ToList();                   // 4. gör en lista
// Te, Kaffe, Croissant, Kanelbulle

Ordningen spelar roll. Efter Select(p => p.Name) finns inget pris kvar.

Gruppera: GroupBy

foreach (var group in menu.GroupBy(p => p.Category))
{
    Console.WriteLine($"{group.Key}: {group.Count()} st");
}
Dryck: 2 st
Smörgås: 2 st
Bakverk: 2 st

Take och Skip

numbers.Take(3)                             // 5, 12, 3
numbers.Skip(3)                             // 8, 20, 1
numbers.Skip(2).Take(2)                     // 3, 8
numbers.OrderByDescending(x => x).Take(3)   // 20, 12, 8 – topp 3

Sidor i en webbshop: sida 2 med 10 per sida = Skip(10).Take(10).

Distinct – ta bort dubbletter

List<int> dice = new List<int> { 3, 6, 3, 1, 6, 6 };
dice.Distinct()                            // 3, 6, 1

menu.Select(p => p.Category).Distinct()    // Dryck, Smörgås, Bakverk

ThenBy – sortera på två saker

menu.OrderBy(p => p.Price)     // 1. sortera på pris
    .ThenBy(p => p.Name)       // 2. samma pris? sortera på namn
// Te, Croissant, Kaffe, Kanelbulle, Ostsmörgås, Skinksmörgås

Kaffe och Croissant kostar båda 30 kr – namnet avgör.

MaxBy och MinBy

menu.Max(p => p.Price)     // 60            – bara värdet
menu.MaxBy(p => p.Price)   // Skinksmörgås  – hela produkten
menu.MinBy(p => p.Price)   // Te

ToDictionary – slå upp med nyckel

Dictionary<string, decimal> prices = menu.ToDictionary(p => p.Name, p => p.Price);

Console.WriteLine(prices["Kaffe"]);   // 30

Första lambdan = nyckel, andra = värde.

Enumerable.Range – skapa tal

Enumerable.Range(1, 10)                          // 1, 2, 3 … 10
Enumerable.Range(1, 10).Where(x => x % 2 == 0)   // 2, 4, 6, 8, 10
Enumerable.Range(1, 5).Select(x => x * x)        // 1, 4, 9, 16, 25

(start, hur många) – inte (start, slut).

Jämför två listor

List<string> programming = new List<string> { "Ada", "Linus", "Grace" };
List<string> math        = new List<string> { "Grace", "Ola", "Ada" };

programming.Concat(math)      // Ada, Linus, Grace, Grace, Ola, Ada
programming.Union(math)       // Ada, Linus, Grace, Ola
programming.Intersect(math)   // Ada, Grace – i båda
programming.Except(math)      // Linus      – bara i första

Query-syntax

// Metodsyntax
var a = menu.Where(p => p.Price < 40).OrderBy(p => p.Price).Select(p => p.Name);

// Query-syntax – liknar SQL
var b = from p in menu
        where p.Price < 40
        orderby p.Price
        select p.Name;

Samma resultat. Lär dig metodsyntaxen först.

Se upp: frågan körs först när den används

List<int> numbers = new List<int> { 1, 2, 3 };

var query = numbers.Where(x => x > 1);            // ingenting händer än
var list  = numbers.Where(x => x > 1).ToList();   // körs nu: 2, 3

numbers.Add(10);

Console.WriteLine(query.Count());   // 3 – 10 kom med
Console.WriteLine(list.Count);      // 2 – en kopia från innan
