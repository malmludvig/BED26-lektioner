Hämta data från ett API

Hittills har all data i våra program funnits i koden eller i en fil. Nu hämtar vi data från internet – ett slumpat Chuck Norris-skämt – med några få rader C#.

1. Vad är ett API?

Ett API (Application Programming Interface) är ett sätt för ett program att prata med ett annat program. Ett webb-API är en adress på internet som ger tillbaka data i stället för en webbsida.

Tänk dig en restaurang

  • Du är vårt program. Du vill ha mat, men du går inte själv in i köket.
  • Servitören är API:et. Du beställer, och servitören kommer tillbaka med maten.
  • Köket är servern. Hur maten lagas behöver du inte veta.

Vårt program skickar en förfrågan (request) till en adress och får tillbaka ett svar (response).

Vårt program  ──  förfrågan: "ge mig ett skämt"  ──▶  api.chucknorris.io
Vårt program  ◀──  svar: JSON med ett skämt  ──────  api.chucknorris.io

2. Prova i webbläsaren först

Öppna den här adressen i webbläsaren:

https://api.chucknorris.io/jokes/random

Du får ingen snygg sida – bara text. Det är JSON, samma format som vi använde för fienderna i Dragon Slayer. Uppdatera sidan så kommer ett nytt skämt.

Så här ser svaret ut, uppställt så att det blir lättare att läsa:

{
  "categories": [],
  "created_at": "2020-01-05 13:42:22.089095",
  "icon_url": "https://api.chucknorris.io/img/avatar/chuck-norris.png",
  "id": "Tck4XfHyQt-90ruRqbn_fw",
  "updated_at": "2020-01-05 13:42:22.089095",
  "url": "https://api.chucknorris.io/jokes/Tck4XfHyQt-90ruRqbn_fw",
  "value": "Fool me once, shame on you. Fool Chuck Norris once and he will roundhouse you in the face."
}
  • JSON består av namn och värden: "value": "Fool me once…"
  • Själva skämtet ligger under namnet "value". Det är det vi vill plocka ut.

3. Hämta skämtet med C#

Skapa ett nytt konsolprojekt och ersätt allt i Program.cs med:

using System.Text.Json;

HttpClient client = new HttpClient();

string url = "https://api.chucknorris.io/jokes/random";
string json = await client.GetStringAsync(url);

JsonDocument document = JsonDocument.Parse(json);
string joke = document.RootElement.GetProperty("value").GetString()!;

Console.WriteLine($"{joke}");

Kör programmet. Varje gång får du ett nytt skämt:

Fool me once, shame on you. Fool Chuck Norris once and he will roundhouse you in the face.

Två nya saker

await – vänta på svaret

Det tar en liten stund att få svar från internet. await betyder: vänta här tills svaret har kommit, fortsätt sedan. Metoder som tar tid heter ofta något med Async i slutet – som GetStringAsync.

! efter GetString()

GetString() kan i teorin ge null (ingenting). Utropstecknet säger till kompilatorn: lita på mig, här finns det text. Då slipper vi en gul varning i Visual Studio.

Om något går fel

  • Ingen internetuppkoppling – programmet kraschar med ett HttpRequestException.
  • Fel namn – skriver du GetProperty("joke") kraschar det med KeyNotFoundException, eftersom det inte finns något "joke" i svaret. Kontrollera alltid namnen i webbläsaren först.

4. Övning

  1. Skriv ut tre skämt efter varandra med en for-loop.
  2. Skriv också ut skämtets "id" på raden ovanför skämtet.
  3. API:et kan ge skämt från en viss kategori. Ändra adressen till https://api.chucknorris.io/jokes/random?category=dev och få bara programmeringsskämt.
Visa facit 
using System.Text.Json;

HttpClient client = new HttpClient();

string url = "https://api.chucknorris.io/jokes/random?category=dev";

for (int i = 0; i < 3; i++)
{
    string json = await client.GetStringAsync(url);

    JsonDocument document = JsonDocument.Parse(json);
    string id = document.RootElement.GetProperty("id").GetString()!;
    string joke = document.RootElement.GetProperty("value").GetString()!;

    Console.WriteLine($"Skämt {id}:");
    Console.WriteLine(joke);
    Console.WriteLine();
}

Vi skapar bara en HttpClient och återanvänder den för alla förfrågningar.

Extra utmaning

Adressen https://api.chucknorris.io/jokes/categories ger en lista med alla kategorier. Låt användaren skriva in en kategori i konsolen och hämta ett skämt från just den.

Visa facit 
using System.Text.Json;

HttpClient client = new HttpClient();

Console.Write("Välj kategori (till exempel dev, food eller sport): ");
string category = Console.ReadLine();

string url = $"https://api.chucknorris.io/jokes/random?category={category}";
string json = await client.GetStringAsync(url);

JsonDocument document = JsonDocument.Parse(json);
string joke = document.RootElement.GetProperty("value").GetString()!;

Console.WriteLine(joke);

Skriver man en kategori som inte finns svarar API:et med ett fel, och programmet kraschar. Det kan man lösa med try/catch – men det är en annan lektion.
