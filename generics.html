Generics

Skriv en klass eller metod en gång – använd den för vilken typ som helst.

Exemplen bygger på Animal, IVehicle och Car från Interfaces i vecka 5.

Generisk metod

{
    Console.WriteLine($"{a} och {b}");

Interface + generics tillsammans

Med where kan vi kräva att T uppfyller ett interface. Då vet vi vad T kan.

class Garage<T> where T : IVehicle
{
    private List<T> vehicles = new List<T>();

    public void Park(T f) { vehicles.Add(f); }

    public void DriveAll()
    {
        foreach (T f in vehicles)
        {
            f.Drive();       // OK – alla T är IVehicle
        }
    }
}

Garage<Car> carGarage = new Garage<Car>();
carGarage.Park(new Car());
carGarage.DriveAll();

Generiska listor: List<T>

En List<T> är en lista som växer av sig själv när du lägger till saker, och som bara tar emot en typ – den du skriver mellan < >.

Skapa och fylla

List<string> names = new List<string>();   // tom lista
names.Add("Ada");
names.Add("Linus");
names.Add("Grace");

List<int> numbers = new List<int> { 5, 12, 3 };   // fyll direkt

De vanligaste metoderna

Kommentaren visar hur listan ser ut efter varje rad.

List<string> names = new List<string> { "Ada", "Linus", "Grace" };

Console.WriteLine(names.Count);              // 3
Console.WriteLine(names[0]);                 // Ada
names[1] = "Bjarne";                         // Ada, Bjarne, Grace
names.Insert(0, "Ola");                      // Ola, Ada, Bjarne, Grace
names.Remove("Ada");                         // Ola, Bjarne, Grace
names.RemoveAt(0);                           // Bjarne, Grace
Console.WriteLine(names.Contains("Grace"));  // True
Console.WriteLine(names.IndexOf("Grace"));   // 1
names.Clear();                               // tom lista, Count är 0

Index börjar på 0. En lista med 3 element har platserna 0, 1 och 2. names[3] kraschar programmet med ArgumentOutOfRangeException.

Loopa igenom en lista

List<string> names = new List<string> { "Ada", "Linus", "Grace" };

    Console.WriteLine(name);
}

// for – när du också behöver platsen (index)
for (int i = 0; i < names.Count; i++)

Fler generiska samlingar

List<T> är vanligast, men det finns fler. Alla fungerar på samma sätt: du väljer typen mellan < >.

// Dictionary – slå upp ett värde med en nyckel

// Queue – först in, först ut (som en kö i kassan)

Bygg en egen generisk lista

Hur fungerar List<T> inuti? Här är en enkel egen version, MyList<T>. Den sparar elementen i en array.

class MyList<T>
{
    private T[] items = new T[10];   // plats för 10 element
    private int count = 0;           // hur många vi har lagt in

    public void Add(T item)
    {
        items[count] = item;         // lägg på första lediga plats
        count++;
    }

    public T Get(int index)
    {
        return items[index];
    }

    public int Count()
    {
        return count;
    }
}

Överallt där det står T fylls typen i när du skapar listan – precis som i Box<T>.

Övning 3. Skriv en generisk metod Last<T> som tar emot en List<T> och returnerar det sista elementet. Testa den med en lista av tal och en lista av namn.

Visa facit 
static T Last<T>(List<T> list)
{
    return list[list.Count - 1];   // sista platsen är Count - 1
}

List<int> numbers = new List<int> { 1, 2, 3 };
List<string> names = new List<string> { "Ada", "Linus", "Grace" };

Console.WriteLine(Last(numbers));   // 3
Console.WriteLine(Last(names));     // Grace

Metoden är skriven en gång, men fungerar för listor av alla typer. T blir int i första anropet och string i andra.

Demo: egen generisk klass i egen generisk lista

Nu kombinerar vi Box<T> och MyList<T> – samma kod som tidigare på sidan. Listan ska innehålla lådor, så T i listan blir Box<string>.

class Box<T>
{
    private T content;

    public void Put(T item) { content = item; }
    public T Take() { return content; }
}

class MyList<T>
{
    private T[] items = new T[10];   // plats för 10 element
    private int count = 0;           // hur många vi har lagt in

    public void Add(T item)
    {
        items[count] = item;         // lägg på första lediga plats
        count++;
    }

    public T Get(int index)
    {
        return items[index];
    }

    public int Count()
    {
        return count;
    }
}
MyList<Box<string>> boxes = new MyList<Box<string>>();

Box<string> box1 = new Box<string>();
box1.Put("Kaffe");
boxes.Add(box1);

Box<string> box2 = new Box<string>();
box2.Put("Te");
boxes.Add(box2);

Console.WriteLine(boxes.Count());         // 2
Console.WriteLine(boxes.Get(1).Take());   // Te

for (int i = 0; i < boxes.Count(); i++)
{
    Console.WriteLine(boxes.Get(i).Take());   // Kaffe, Te
}
KodT blir
MyList<Box<string>>Box<string> – listan sparar lådor
Box<string>string – lådan sparar text

boxes.Get(1).Take() läses från vänster: Get(1) hämtar lådan på plats 1, Take() tar ut texten ur lådan.
