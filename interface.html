Övning: Interface

Fem övningar som börjar enkelt och blir lite svårare. Försök själv först – öppna facit när du är klar.

Kom ihåg

  • Ett interface är ett kontrakt: det säger vad en klass kan göra, inte hur.
  • Namnet börjar med I, t.ex. ISound.
  • Klassen som implementerar interfacet måste ha alla metoder i det.

Övning 1: Något som låter

Så här ska det se ut när du är klar:

classDiagram
  class ISound {
    <<interface>>
    +MakeSound() string
  }
  class Dog { +MakeSound() string }
  class Cat { +MakeSound() string }
  class Car { +MakeSound() string }
  ISound <|.. Dog
  ISound <|.. Cat
  ISound <|.. Car

Steg 1: Skapa interfacet

Skapa ett nytt konsolprojekt. Lägg till en fil ISound.cs med ett interface som har metoden string MakeSound().

Visa facit 
interface ISound
{
    string MakeSound();
}

Ingen kropp med { } – bara löftet om att metoden finns.

Steg 2: Hund och Katt

Skapa klasserna Dog och Cat. Båda ska implementera ISound. Hunden säger "Voff!" och katten "Mjau!".

Visa facit 
class Dog : ISound
{
    public string MakeSound() => "Voff!";
}

class Cat : ISound
{
    public string MakeSound() => "Mjau!";
}

Testa: ta bort metoden MakeSound från Cat. Vilket fel får du? Sätt tillbaka den.

Steg 3: En Bil

Skapa en klass Car som också implementerar ISound och säger "Tut tut!".

Visa facit 
class Car : ISound
{
    public string MakeSound() => "Tut tut!";
}

Fundera: varför hade det varit konstigt att lösa det här med en basklass Animal? (En bil är inte ett djur – men den kan låta.)

Steg 4: Låt alla låta

I Program.cs: skapa en List<ISound> med en hund, en katt och en bil. Loopa igenom listan och skriv ut ljudet.

Visa facit 
List<ISound> things = new List<ISound> { new Dog(), new Cat(), new Car() };

foreach (ISound thing in things)
{
    Console.WriteLine(thing.MakeSound());
}

Utskrift:

Voff!
Mjau!
Tut tut!

Loopen vet inte om det är en hund eller en bil – den vet bara att alla kan låta. Det är polymorfism.

Extra: Två interface

Skapa ett interface IMovable med metoden void Move(). Låt Dog och Car implementera det (katten är lat). Gör en List<IMovable> och anropa Move() på alla.

Visa facit 
interface IMovable
{
    void Move();
}

class Dog : ISound, IMovable
{
    public string MakeSound() => "Voff!";
    public void Move() => Console.WriteLine("Hunden springer");
}

class Car : ISound, IMovable
{
    public string MakeSound() => "Tut tut!";
    public void Move() => Console.WriteLine("Bilen kör");
}

// I Program.cs
List<IMovable> movables = new List<IMovable> { new Dog(), new Car() };

foreach (IMovable r in movables)
{
    r.Move();
}

En klass kan implementera flera interface – separera dem med kommatecken.

Klart när

  • ☐ ISound finns och har metoden MakeSound().
  • ☐ Hund, Katt och Bil implementerar ISound.
  • ☐ En loop över en List<ISound> skriver ut alla ljud.
  • ☐ Du kan förklara skillnaden mellan "är en" (arv) och "kan" (interface).

Övning 2: Figurer

Ett interface kan också innehålla en egenskap (property), inte bara metoder.

  1. Skapa ett interface IShape med egenskapen string Name { get; } och metoden double Area().
  2. Skapa Circle (har en radie) och Rectangle (har bredd och höjd). Båda implementerar IShape.
  3. Lägg en cirkel med radie 2 och en rektangel 3 × 4 i en List<IShape>.
  4. Skriv ut namn och area för varje figur, och till sist den totala arean.

Tips: arean av en cirkel är Math.PI * radius * radius.

Visa facit 
interface IShape
{
    string Name { get; }
    double Area();
}

class Circle : IShape
{
    private double radius;
    public Circle(double radius) { this.radius = radius; }

    public string Name => "Cirkel";
    public double Area() => Math.PI * radius * radius;
}

class Rectangle : IShape
{
    private double width, height;
    public Rectangle(double width, double height) { this.width = width; this.height = height; }

    public string Name => "Rektangel";
    public double Area() => width * height;
}

// I Program.cs
List<IShape> shapes = new List<IShape> { new Circle(2), new Rectangle(3, 4) };
double total = 0;

foreach (IShape f in shapes)
{
    Console.WriteLine($"{f.Name}: {f.Area():0.00}");
    total += f.Area();
}
Console.WriteLine($"Total area: {total:0.00}");

Utskrift:

Cirkel: 12,57
Rektangel: 12,00
Total area: 24,57

Varje figur räknar ut sin egen area. Loopen behöver inte veta om det är en cirkel eller en rektangel.

Övning 3: Betalsätt

Ett interface kan användas som parameter i en metod. Då fungerar metoden för alla klasser som implementerar det.

  1. Skapa ett interface IPaymentMethod med metoden string Pay(decimal amount).
  2. Skapa tre klasser: Card, Swish och Cash. Varje klass returnerar en egen text, t.ex. "Swishade 120 kr".
  3. Skriv en metod static void Pay(IPaymentMethod method, decimal amount) i Program.cs som skriver ut resultatet.
  4. Anropa metoden en gång med varje betalsätt.
Visa facit 
interface IPaymentMethod
{
    string Pay(decimal amount);
}

class Card : IPaymentMethod
{
    public string Pay(decimal amount) => $"Drog {amount} kr från kortet";
}

class Swish : IPaymentMethod
{
    public string Pay(decimal amount) => $"Swishade {amount} kr";
}

class Cash : IPaymentMethod
{
    public string Pay(decimal amount) => $"Tog emot {amount} kr i kontanter";
}

// I Program.cs
Pay(new Card(), 45);
Pay(new Swish(), 120);
Pay(new Cash(), 30);

static void Pay(IPaymentMethod method, decimal amount)
{
    Console.WriteLine(method.Pay(amount));
}

Utskrift:

Drog 45 kr från kortet
Swishade 120 kr
Tog emot 30 kr i kontanter

Vill kaféet börja ta emot ett nytt betalsätt behöver vi bara skriva en ny klass. Metoden Pay ändras inte.

Övning 4: Hitta felen

Koden nedan kompilerar inte. Den innehåller tre fel. Hitta dem och rätta koden.

interface ILamp
{
    void TurnOn();
    void TurnOff();
}

class CeilingLamp : ILamp
{
    private void TurnOn() { Console.WriteLine("Taklampan lyser"); }
}

// I Program.cs
ILamp lamp = new ILamp();
lamp.TurnOn();
Visa facit
  1. TurnOn() är private. Metoder som implementerar ett interface måste vara public.
  2. CeilingLamp saknar metoden TurnOff(). Alla metoder i interfacet måste finnas.
  3. Man kan inte skriva new ILamp(). Ett interface är bara ett kontrakt – man skapar objekt av en klass som implementerar det.
class CeilingLamp : ILamp
{
    public void TurnOn() { Console.WriteLine("Taklampan lyser"); }
    public void TurnOff() { Console.WriteLine("Taklampan är släckt"); }
}

// I Program.cs
ILamp lamp = new CeilingLamp();
lamp.TurnOn();
lamp.TurnOff();

Variabeln får gärna vara av typen ILamp, men objektet måste vara en CeilingLamp.

Övning 5: Smarta hemmet (designa själv)

Nu designar du själv. Börja med att rita ett UML-diagram innan du kodar.

"I ett smart hem finns en lampa, en högtalare och en kaffebryggare. Alla prylar har ett namn och kan slås på. Hemmet håller reda på alla prylar och kan slå på allt med ett kommando."

  1. Stryk under substantiv (klasser), egenskaper (attribut) och verb (metoder).
  2. Vad har alla prylar gemensamt? Det blir ditt interface.
  3. Rita diagrammet. Glöm inte relationen mellan hemmet och prylarna.
  4. Skriv koden och testa att TurnOnAll() fungerar.
Visa facit 
classDiagram
  class ISmartDevice {
    <<interface>>
    +Name: string
    +TurnOn()
  }
  class Home {
    -devices: List~ISmartDevice~
    +Add(device: ISmartDevice)
    +TurnOnAll()
  }
  ISmartDevice <|.. Lamp
  ISmartDevice <|.. Speaker
  ISmartDevice <|.. CoffeeMaker
  Home "1" --> "0..*" ISmartDevice : har

interface ISmartDevice
{
    string Name { get; }
    void TurnOn();
}

class Lamp : ISmartDevice
{
    public string Name => "Lampan";
    public void TurnOn() => Console.WriteLine("Lampan lyser");
}

class Speaker : ISmartDevice
{
    public string Name => "Högtalaren";
    public void TurnOn() => Console.WriteLine("Högtalaren spelar musik");
}

class CoffeeMaker : ISmartDevice
{
    public string Name => "Kaffebryggaren";
    public void TurnOn() => Console.WriteLine("Kaffebryggaren brygger kaffe");
}

class Home
{
    private List<ISmartDevice> devices = new List<ISmartDevice>();

    public void Add(ISmartDevice device) => devices.Add(device);

    public void TurnOnAll()
    {
        foreach (ISmartDevice device in devices)
        {
            Console.Write($"{device.Name}: ");
            device.TurnOn();
        }
    }
}

// I Program.cs
Home home = new Home();
home.Add(new Lamp());
home.Add(new Speaker());
home.Add(new CoffeeMaker());
home.TurnOnAll();

Utskrift:

Lampan: Lampan lyser
Högtalaren: Högtalaren spelar musik
Kaffebryggaren: Kaffebryggaren brygger kaffe

Home känner bara till ISmartDevice. Köper vi en robotdammsugare skriver vi en ny klass – Home behöver inte ändras.
