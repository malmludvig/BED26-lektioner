Generics

Skriv en klass eller metod en gång – använd den för vilken typ som helst.

Du har redan använt generics

List<int>    numbers = new List<int>    { 1, 2, 3 };
List<string> names   = new List<string> { "Ada", "Linus" };
List<Animal> animals = new List<Animal>();

T i List<T> är en typ-parameter – en plats där du fyller i en typ.

Typsäkert

List<int> numbers = new List<int>();
numbers.Add(5);
numbers.Add("hej");   // FEL – stoppas redan när du kompilerar

Fel typ blir rött i Visual Studio – inte en krasch när programmet körs.

Utan generics: ArrayList

ArrayList old = new ArrayList();
old.Add(5);
old.Add("hej");                // tillåts – allt är object

int second = (int)old[1];      // KRASCHAR när programmet körs

Därför använder vi alltid List<T>.

Egen generisk klass

class Box<T>
{
    private T content;

    public void Put(T item) { content = item; }
    public T Take() { return content; }
}

T är en platshållare. Den fylls i när du skapar en Box.

En klass – många typer

Box<int>    numberBox = new Box<int>();
Box<string> wordBox   = new Box<string>();

numberBox.Put(42);
wordBox.Put("Hej!");

int n = numberBox.Take();   // 42 – ingen typomvandling behövs

Egen generisk lista: MyList<T>

class MyList<T>
{
    private T[] items = new T[10];   // plats för 10 element
    private int count = 0;           // hur många vi har lagt in

    public void Add(T item)
    {
        items[count] = item;
        count++;
    }

    public T Get(int index)
    {
        return items[index];
    }

    public int Count()
    {
        return count;
    }
}

Använda MyList<T>

MyList<string> names = new MyList<string>();
names.Add("Ada");
names.Add("Linus");
names.Add("Grace");

Console.WriteLine(names.Count());   // 3
Console.WriteLine(names.Get(1));    // Linus

MyList<int> numbers = new MyList<int>();
numbers.Add(5);
Console.WriteLine(numbers.Get(0));  // 5

Så fungerar List<T> inuti: en array. List<T> gör dessutom arrayen större när den blir full.

Box<T> i MyList<T>

MyList<Box<string>> boxes = new MyList<Box<string>>();

Box<string> box1 = new Box<string>();
box1.Put("Kaffe");
boxes.Add(box1);

Box<string> box2 = new Box<string>();
box2.Put("Te");
boxes.Add(box2);

Console.WriteLine(boxes.Count());         // 2
Console.WriteLine(boxes.Get(1).Take());   // Te

Listans T blir Box<string>. Lådans T blir string. Prova demot

Generisk metod

static void PrintTwo<T>(T a, T b)
{
    Console.WriteLine($"{a} och {b}");
}

PrintTwo(1, 2);           // T blir int
PrintTwo("katt", "hund"); // T blir string

Krav på T med where

class Garage<T> where T : IVehicle
{
    private List<T> vehicles = new List<T>();

    public void Park(T v) { vehicles.Add(v); }

    public void DriveAll()
    {
        foreach (T v in vehicles)
        {
            v.Drive();       // OK – alla T är IVehicle
        }
    }
}

Generics + interface: vi vet vad T kan.
